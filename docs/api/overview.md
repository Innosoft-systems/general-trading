# API Overview

## Public APIs

- content fetching
- tours listing and detail
- gallery and static pages
- contact submission
- legal documents
- payment page and payment attempt initiation
- payment status and invoice access

## Admin APIs

- auth and session management
- content CRUD
- legal version publishing
- payment settings and provider mappings
- payment attempts, consent logs, invoices, audit logs

## Webhook APIs

- provider-specific callbacks under `/webhooks/providers/:providerKey`
